Hidden in plain sight

A C program that tucks a secret file into the last bit of every pixel byte of a BMP image, then reads it back out.

Flip one bit, change nothing you can see

Each pixel byte stores one secret bit in its last position. Type a character and watch eight pixel bytes take on its 8 bits.

Will your file fit?

Capacity is width × height × 3 bytes. The program accepts the file only if the image has more bytes than the file needs.
